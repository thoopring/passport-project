> 작성: 2026-04-30
> 두 가지 다 "지금 이해는 해두고, 시간 될 때 액션" 정도로 충분.

## 1. PostHog 가 뭐예요?

### 한 줄 정의
**사용자가 사이트에서 무엇을 했는지 추적하는 무료 도구.** Google Analytics(GA4)랑 비슷하지만 더 깊이 있게 들여다볼 수 있어요.

### 왜 필요한가요?
지금까지는 "방문자가 몇 명 왔는지"만 알 수 있었어요 (GA4). 그런데 **돈을 벌려면 더 깊은 질문에 답할 수 있어야 해요:**

- 100명이 홈에 왔는데, 얼마가 위자드 시작했어?
- 위자드 시작한 사람 중 얼마가 끝까지 답했어?
- 한국어 사용자 vs 영어 사용자 중 누가 더 결제까지 가?
- 가장 많이 떠나는 단계가 어디야?

이런 질문에 답이 있으면 **다음에 뭘 고쳐야 매출이 늘지** 보여요. 답이 없으면 추측 게임.

### GA4랑 뭐가 달라요?
| | GA4 (이미 있음) | PostHog (추가) |
|---|---|---|
| 강점 | "어디서 왔는지" (구글 검색? 페북 광고?) | "안에서 뭘 했는지" (clicks, scrolls, drop-offs) |
| 깔때기 분석 | 가능하지만 복잡 | 클릭 몇 번이면 그래프 |
| 비용 | 무료 | 무료 (월 100만 이벤트까지) |
| 보는 곳 | analytics.google.com | us.posthog.com |

→ **둘 다 쓰면 풀 그림.** 하나만 쓰면 반쪽.

### 우리가 추적하는 8개 이벤트
이미 코드에 깔려있고, PostHog 켜기만 하면 데이터 모이기 시작합니다:

| 이벤트 | 언제 발생 |
|---|---|
| `page_view` | 페이지 이동할 때마다 |
| `wizard_started` | 사용자가 여행 계획 만들기 시작 |
| `checkout_started` | 결제 페이지로 이동 |
| `checkout_completed` | 결제 완료 후 플랜 받음 |
| `account_signup` | 첫 로그인 |
| `account_visit` | /account 페이지 방문 |
| `referral_shared` | 공유 링크 복사 |
| `credit_used` | 추천 크레딧 사용 |

각 이벤트에 **언어 정보**도 자동으로 붙어요. 한국어 사용자만 따로 분석 가능.

## PostHog 켜는 방법 (5분, 한 번만)

### 1단계: PostHog 가입
1. https://us.posthog.com 접속
2. **Sign up** 클릭
3. 구글 계정으로 로그인 (가장 빠름)
4. 프로젝트 이름: "gliddy" (자유)
5. 지역: **US** (미국 사용자 많을 가능성) 또는 **EU** (GDPR 안전)

### 2단계: API 키 복사
가입 끝나면 자동으로 대시보드 이동.
1. 좌측 하단 **Settings** 클릭
2. **Project** 탭 → **Project API Key** 항목
3. `phc_`로 시작하는 긴 문자열 복사 (예: `phc_aBcDeFgHiJkLmNoPqRsTuVwXyZ123456`)

### 3단계: Vercel에 키 등록
1. https://vercel.com/dashboard 접속
2. `passport-project` 프로젝트 클릭
3. 상단 **Settings** 탭
4. 좌측 **Environment Variables** 메뉴
5. **Add New** 버튼
6. 입력:
   - Name: `NEXT_PUBLIC_POSTHOG_KEY`
   - Value: 복사한 `phc_...` 값 그대로 붙여넣기
   - Environments: **Production** + **Preview** 둘 다 체크
7. **Save**

### 4단계: 재배포
- Vercel 대시보드 → **Deployments** 탭
- 가장 최근 deployment의 우측 `...` 메뉴 → **Redeploy**
- "Use existing Build Cache" 체크하고 Redeploy 클릭
- 1-2분 후 배포 완료

### 5단계: 데이터 확인 (배포 24시간 후)
- https://us.posthog.com 다시 접속
- 좌측 **Activity** 메뉴 → 라이브 이벤트 확인
- 좌측 **Insights** 메뉴 → 깔때기 만들기 시도

---

## PostHog 첫 깔때기 만들기 (10분, 학습 겸)

이미 데이터가 24시간 정도 모인 후:

1. 좌측 **Insights** → **+ New Insight**
2. **Funnel** 선택
3. Step 1: `page_view` 이벤트 선택
4. **Add step** → `wizard_started`
5. **Add step** → `checkout_completed`
6. 우측 **Breakdown** → `locale` 선택
7. **Save**

→ 결과: "한국어/영어/일본어/중문/프랑스어 사용자 각각의 깔때기 전환률" 그래프.

이 그래프 일주일에 한 번씩 보면서:
- 어느 단계에서 가장 많이 떠나는지 확인
- 어느 언어가 전환률 약한지 확인
- 그게 다음 우선순위

## 비용 걱정?
**월 100만 이벤트까지 무료.** 우리 사이트 트래픽이 폭발할 때까지는 전혀 안 듦.
- 1만 명 방문/월 = 약 5-10만 이벤트 → 한참 무료
- 10만 명/월 = 50-100만 이벤트 → 무료 한도 근접

월 100만 넘으면 그때 가서 paid plan 결정 (월 $0.00031/이벤트, 10만 추가 이벤트 = $31).

## 2. SEO 블로그 시드 가 뭐예요?

### 한 줄 정의
**구글에서 우리 사이트로 사람이 자연스럽게 흘러들게 하는 글 쓰기.**

### 왜 필요한가요?
지금 사이트는 멋있게 만들어졌지만 **구글에 노출이 안 됩니다.** 사람들이 검색해서 우리 사이트를 발견하려면:

> "도쿄 4일 일정 추천" → 구글 → 블로그 글 1개 → 거기서 우리 샘플 링크 → 결제

이 흐름을 만들어야 해요. 그 시작점이 **블로그 글**.

### 어떤 글을 써요?
**우리 13개 샘플을 SEO entry point**로 활용:

| 검색 키워드 (예) | 우리 글 제목 (예) | 연결 |
|---|---|---|
| "도쿄 4일 일정 AI" | "AI가 짜준 도쿄 4일 일정 — 시부야부터 가마쿠라까지" | tokyo 샘플 링크 |
| "Reykjavik 4-day couple itinerary" | "I asked an AI to plan a 4-day Reykjavik trip. Here's what it gave me." | reykjavik 샘플 |
| "Cusco Machu Picchu 5일" | "쿠스코 마추픽추 5일 — 고산병 안 걸리는 일정" | cusco 샘플 |

### 구조 (글마다 동일)
```
1. 도입 (200단어): "여행 계획 짜기 너무 힘들죠?"
2. 우리 AI가 도쿄 4일 일정 짜준 결과 (요약 + 스크린샷)
3. Day-by-day 핵심만 발췌 (각 day 2-3 stops)
4. 직접 보기 → 우리 샘플 페이지 링크 (CTA)
5. 마무리: "당신만의 일정도 만들어보세요" → 위자드 링크
```

### 어디다 써요?
- 우리 사이트의 `/blog/[slug]` 페이지 (이미 인프라 있음)
- 또는 외부 (브런치/티스토리/네이버블로그) — 백링크 효과

### 글 1편 = 얼마 시간?
**1편당 1-2시간** 정도. 13개 다 안 해도 됨:
- 검색량 큰 도시부터 6편 (Tokyo / Paris / Bali / Reykjavik / Cusco / Dubai)
- 한 달 동안 천천히 1주 1편 페이스 OK

### 효과는 언제부터?
- 글 publish → 구글 인덱싱: 1-2주
- 검색 순위 상승: 2-3개월
- 첫 organic 트래픽: 1-3개월
- → **느린 작업이지만 한 번 자리 잡으면 무한 무료 트래픽**

### 누가 써요?
**파운더(본인)가 직접.** 이유:
- 본인이 가장 product 잘 알고 있음
- AI tool로 보완 가능 (Claude 한테 초안 부탁 → 본인이 다듬기)
- 톤이 일관됨

### 키워드 리서치 (참고용)
무료 도구:
- https://trends.google.com — 검색 트렌드
- https://keywordtool.io/google — 자동완성 키워드
- https://answerthepublic.com — "도쿄 일정 어떻게" 같은 질문형 키워드

## 요약 — SEO 블로그 액션 체크리스트

- [ ] 우선 1편만 시도 (Tokyo부터, 한국어로)
- [ ] 키워드 1개 정함 ("도쿄 4일 일정 추천")
- [ ] 1500-2000자 정도 작성
- [ ] `/blog/[slug]` 페이지에 publish
- [ ] 검색 콘솔(search.google.com/search-console) 등록 → 인덱싱 요청
- [ ] 1-2주 기다림
- [ ] 효과 보면 다음 5편 작성

→ **지금 당장 안 해도 OK.** 다른 작업 마무리하고 천천히 진행.

## 두 작업의 관계

| | PostHog | SEO 블로그 |
|---|---|---|
| 무엇 | 데이터 수집 | 사람 끌어오기 |

| 효과 시점 | 즉시 (데이터 모이기 시작) | 1-3개월 후 |
| 우선순위 | **높음 (의사결정 데이터)** | 중간 (장기 트래픽) |

→ **PostHog 먼저, 블로그는 천천히.**
